    The road aheadالطريق أمامنا

      How every lesson is builtكيف يُبنى كل درس

      Code that evolvesكود يتطوّر

      Each idea starts with the obvious solution, then improves it version by version. Every version fixes a named defect — and the tests ask you which version is better and why.

      تبدأ كل فكرة بالحل البديهي ثم تُحسَّن نسخةً بعد نسخة. تعالج كل نسخة عيبًا مسمّى — وتسألك الاختبارات أي النسخ أفضل ولماذا.

      An AI lens on everythingمنظور الذكاء الاصطناعي في كل شيء

      Each concept shows where it decides whether a model trains well or fails silently: features and labels, leakage, encoding, API data, drift.

      يبيّن كل مفهوم أين يقرّر نجاح تدريب النموذج أو فشله الصامت: الخصائص والتسمية، والتسرّب، والترميز، وبيانات الواجهات، والانزياح.

      Problem threadsخيوط المشكلات

      The same kinds of problem return in later chapters solved better, with the side effects and gaps of the old solution named — so you see why each new tool exists.

      تعود أنواع المشكلات نفسها في فصول لاحقة بحلول أفضل، مع تسمية آثار الحل القديم وثغراته الجانبية — لترى لماذا وُجدت كل أداة جديدة.

      Fourteen kinds of questionأربعة عشر نوعًا من الأسئلة

      True/false, multiple choice, fill in the blank, match, re-order, order the code, predict the output, trace, find the error, complete, compare and contrast, write code. Each has a hint, an answer and an explanation — all hidden until you ask — and links back to what to review.

      صح/خطأ، واختيار من متعدد، وإكمال الفراغ، والتوصيل، وإعادة الترتيب، وترتيب أسطر الكود، وتوقّع المُخرَج، والتتبّع، واكتشاف الخطأ، والإكمال، والمقارنة، وكتابة الكود. لكل سؤال تلميح وجواب وشرح — كلها مخفية حتى تطلبها — وروابط تعيدك إلى ما تراجعه.

      Why this course existsلماذا هذا المقرر

      Most failed analyses and most failed models do not fail loudly. A column loads as text, a date is read as a number, a join duplicates rows, a chart quietly lies — and the result looks plausible. This course teaches you to see those failures before they reach a decision.

      أغلب التحليلات الفاشلة وأغلب النماذج الفاشلة لا تفشل بصخب. عمود يُحمَّل نصًّا، وتاريخ يُقرأ رقمًا، ودمج يكرّر الصفوف، ورسم يكذب بهدوء — والنتيجة تبدو معقولة. يعلّمك هذا المقرر أن ترى هذه الأعطال قبل أن تصل إلى قرار.
