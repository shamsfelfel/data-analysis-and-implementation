The problemالمشكلة

The manager sends September's file and asks: “which three items earn the most?” You could answer in Excel in ten minutes, in Power BI Desktop in twenty, or in a notebook in fifteen. All three answers will be right — today. Next month the manager sends October's file and asks the same question. Which tool can answer again without you redoing every click? AI lens — the tool decides whether the training table can be rebuiltمنظور الذكاء الاصطناعي — الأداة تحسم إمكانية إعادة بناء جدول التدريب

A model is trained on a table, and a table is the output of every cleaning decision made on the way. Suppose someone fixes the cafeteria's price typo (a Shawarma Wrap at 120.0 instead of 12.0) by typing over the cell in Excel and trains a demand model on the saved file. Next month nobody can say which of the 771 order lines were hand-corrected, so the model cannot be retrained from the new export — and a bug in the prices cannot be traced. Tools whose steps are text (a script, Power Query) keep the raw file untouched and make the training table re-derivable. This is why the later lessons in this chapter keep returning to the raw file (thread P-CLEAN).

يُدرَّب النموذج على جدول، والجدول هو ناتج كل قرار تنظيف اتُّخذ في الطريق. افترض أن شخصًا صحّح خطأ السعر في الكافتيريا (Shawarma Wrap بسعر 120.0 بدل 12.0) بالكتابة فوق الخلية في Excel ثم درّب نموذج طلب على الملف المحفوظ. في الشهر القادم لا أحد يستطيع أن يقول أيّ أسطر الطلبات الـ 771 صُحّحت يدويًّا، فلا يمكن إعادة تدريب النموذج من التصدير الجديد — ولا يمكن تتبّع خطأ في الأسعار. أما الأدوات التي خطواتها نص (سكربت أو Power Query) فتُبقي الملف الخام سليمًا وتجعل جدول التدريب قابلًا لإعادة الاشتقاق. ولذلك تعود دروس هذا الفصل اللاحقة مرارًا إلى الملف الخام (خيط P-CLEAN).

Concept 2 — Python: install it, then prove which one you are runningالمفهوم 2 — Python: ثبّته ثم أثبت أيّ نسخة منه تعمل

The problemالمشكلة

“I installed Python” can mean four different things: it is installed but not on the PATH (so the terminal cannot find it); two copies are installed and the wrong one answers; the Microsoft Store shortcut answers instead of the real program; or the terminal window you are typing in was opened before the install. None of these shows an error at install time. Each shows up an hour later as “ModuleNotFoundError” for a package you are sure you installed.

عبارة «ثبّتُّ Python» قد تعني أربعة أشياء مختلفة: ثُبّت لكنه ليس في PATH (فلا تجده الطرفية)؛ أو ثُبّتت نسختان فتجيب الخاطئة؛ أو يجيب اختصار متجر مايكروسوفت بدل البرنامج الحقيقي؛ أو أن نافذة الطرفية التي تكتب فيها فُتحت قبل التثبيت. لا شيء من هذا يُظهر خطأً وقت التثبيت. وكل منها يظهر بعد ساعة في صورة «ModuleNotFoundError» لحزمة أنت واثق أنك ثبّتها.

Five words before the commandsخمس كلمات قبل الأوامر

Python is a programming language, and also the program that runs it. That program is the interpreter: it reads your .py file or notebook cell and executes it. On Windows it is python.exe; on macOS and Linux it is usually called python3.

بايثون (Python) لغة برمجة، وهي أيضًا البرنامج الذي ينفّذها. وهذا البرنامج هو المفسِّر (interpreter): يقرأ ملف .py أو خلية الدفتر وينفّذه. وهو على ويندوز python.exe، وعلى macOS وLinux يُسمّى عادةً python3.

A package is a bundle of Python code you load with import — pandas is a package. pip is Python's installer for packages: pip install pandas downloads pandas from PyPI, the public package index, into the Python that pip belongs to.

الحزمة (package) مجموعة كود بايثون تحمّلها بـ import — فـ pandas حزمة. وpip هو مثبِّت الحزم في Python: الأمر pip install pandas ينزّل pandas من PyPI، وهو الفهرس العام للحزم، إلى نسخة Python التي يتبع لها pip.

The PATH is the list of folders the terminal searches, in order, when you type a command such as python. The first match wins. Almost every “wrong Python” problem in this lesson is a PATH problem in disguise.

ومتغيّر المسار PATH هو قائمة المجلدات التي تبحث فيها الطرفية بالترتيب حين تكتب أمرًا مثل python. وأول تطابق هو الذي يفوز. وتقريبًا كل مشكلة «نسخة Python الخاطئة» في هذا الدرس هي مشكلة PATH متنكّرة.

Which version?أي إصدار؟

Any of Python 3.11, 3.12 or 3.13 is fine for this course (the outputs here come from 3.13). Do not install the newest release the week it appears: data and machine-learning libraries publish their compiled builds for a new Python version weeks or months later, and on a brand-new version pip install can fail with “no matching distribution”. Choose the 64-bit installer.

أي إصدار من Python 3.11 أو 3.12 أو 3.13 مناسب لهذا المقرر (مخرجات هذا الدرس من 3.13). لا تثبّت أحدث إصدار في الأسبوع الذي يصدر فيه: فمكتبات البيانات والتعلّم الآلي تنشر نسخها المترجمة للإصدار الجديد من Python بعد أسابيع أو أشهر، وعلى إصدار جديد جدًّا قد يفشل pip install برسالة «no matching distribution». اختر مثبّت 64 بت.

Start from the map. Your operating system picks the route; the same check (python --version shows 3.11–3.13) decides whether to go on or to open the troubleshooting table. Power BI Desktop is a separate branch with its own rule: Windows only.

Why python -m pip beats pipلماذا python -m pip أفضل من pip

pip on its own is a separate little program that the terminal finds through the PATH — so it may belong to a different Python than the python you just checked. python -m pip says “run the pip of this exact interpreter”, so the package lands where import will look for it. Use the long form until you have a reason not to; it removes a whole class of “I installed it but it is not there” bugs.

الأمر pip وحده برنامج صغير منفصل تجده الطرفية عبر PATH — فقد يتبع لنسخة Python غير التي فحصتها للتو. أما python -m pip فيقول «شغّل pip الخاص بهذا المفسِّر بعينه»، فتحط الحزمة حيث سيبحث عنها import. استعمل الصيغة الطويلة حتى يكون لديك سبب آخر؛ فهي تزيل فئة كاملة من أخطاء «ثبّتّها لكنها غير موجودة».

You install Python, leave your terminal window open, and type python --version: “not recognized”. What is the most likely cause?ثبّتّ Python وتركت نافذة الطرفية مفتوحة، ثم كتبت python --version فجاءت «not recognized». ما السبب الأرجح؟

A terminal reads the PATH once, when it starts. The installer changed the PATH for programs started afterwards, so an already-open window cannot see it. Re-installing (the tempting answer) fixes nothing; a restart is rarely needed. If a brand-new terminal still fails, check the “Add python.exe to PATH” box (run the installer again and choose Modify) and the Store alias.

AI lens — the version you run is part of the experimentمنظور الذكاء الاصطناعي — الإصدار الذي تشغّله جزء من التجربة

Machine-learning libraries ship compiled builds, one per Python version and operating system. Concept 3 — Virtual environments: one project, one toolboxالمفهوم 3 — البيئات الافتراضية: مشروع واحد، صندوق أدوات واحد

The problemالمشكلة

pip install pandas into the system Python works and prints no warning. But the system Python is one shared toolbox for every project on the machine. After a few months it holds hundreds of packages nobody chose on purpose; the day a second project needs a different version of the same package, installing for one silently breaks the other. On the machine used for this lesson the system Python already holds 223 packages. On newer Debian/Ubuntu and Homebrew installs, pip refuses outright: error: externally-managed-environment.

الأمر pip install pandas في Python النظام ينجح ولا يطبع أي تحذير. لكن Python النظام صندوق أدوات مشترك واحد لكل مشاريع الجهاز. وبعد أشهر يضم مئات الحزم لم يخترها أحد عن قصد؛ وفي اليوم الذي يحتاج فيه مشروع ثانٍ إلى إصدار مختلف من الحزمة نفسها، يكسر التثبيت لأحدهما المشروعَ الآخر بصمت. وفي الجهاز المستعمل لهذا الدرس يضم Python النظام فعلًا 223 حزمة. وفي تثبيتات Debian/Ubuntu وHomebrew الأحدث يرفض pip الأمر صراحةً: error: externally-managed-environment.

What a virtual environment isما هي البيئة الافتراضية

A virtual environment (venv) is a folder that holds its own small copy of the Python launcher and its own empty place for packages. When it is active, python and pip mean the ones in that folder, so everything you install lands there and nowhere else. Delete the folder and the project's packages are gone, with the rest of the machine untouched.

البيئة افتراضية (virtual environment) أو venv مجلد فيه نسخته الصغيرة الخاصة من مشغّل Python ومكان فارغ خاص للحزم. وحين تكون مفعّلة يصير python وpip هما اللذين في ذلك المجلد، فيحطّ كل ما تثبّته هناك ولا يحطّ في غيره. احذف المجلد فتزول حزم المشروع، ويبقى بقية الجهاز سليمًا.

Honesty box: what an environment costsصندوق الصراحة: كلفة البيئة

An environment costs disk (about 380 MB here), time (minutes per rebuild), and one more thing to remember (activate it!). Do not put .venv inside a folder that OneDrive, Dropbox or Google Drive synchronises: tens of thousands of small files make sync slow and can corrupt the environment. And if the project needs GPU libraries or non-Python binaries, conda (Concept 2) may be the easier route.

AI lens — an environment is part of the modelمنظور الذكاء الاصطناعي — البيئة جزء من النموذج

A trained model is the product of data, code and the library versions that ran the code: the same training script with another NumPy or scikit-learn release can initialise, round or split differently and give a model that scores a little differently — with no error. GPU stacks make isolation more urgent: the deep-learning library, its CUDA build and the GPU driver must match, and one global pip install by another project can silently swap the build. That is why model repositories ship a pinned requirements file (or a container) and why a model card records the framework versions: the environment is part of the experiment.

النموذج المدرَّب ناتج عن البيانات والكود وإصدارات المكتبات التي شغّلت الكود: فالسكربت نفسه مع إصدار آخر من NumPy أو scikit-learn قد يهيّئ أو يقرّب أو يقسّم بشكل مختلف فيعطي نموذجًا تختلف درجته قليلًا — دون أي خطأ. وتجعل حِزَم GPU العزل أشدّ إلحاحًا: فمكتبة التعلّم العميق ونسخة CUDA الخاصة بها وتعريف بطاقة GPU يجب أن تتطابق، وقد يبدّل pip install عام من مشروع آخر النسخة بصمت. ولهذا تُرفق مستودعات النماذج ملف متطلبات مثبَّتًا (أو حاوية)، ولهذا تسجّل بطاقة النموذج (model card) إصدارات الأطر: البيئة جزء من التجربة.

The problemالمشكلة

Excel opens everything, and that is exactly the trap. Double-click a CSV and Excel decides, silently, what each column is: a date, a number, text; which encoding the letters use; which character separates the columns. When it guesses wrong, nothing is flagged — the Arabic item names turn into symbols, or all the columns land in column A. And the formula in a tutorial may simply not exist in the Excel you own.

يفتح Excel كل شيء، وهذا بالضبط هو الفخ. انقر نقرًا مزدوجًا على ملف CSV فيقرّر Excel بصمت ما هو كل عمود: تاريخ أو رقم أو نص؛ وأي ترميز تستعمله الحروف؛ وأي محرف يفصل الأعمدة. وحين يخطئ التخمين لا يُشار إلى شيء — فتتحول أسماء الأصناف العربية إلى رموز، أو تهبط الأعمدة كلها في العمود A. وقد تكون الصيغة في شرح ما غير موجودة أصلًا في نسخة Excel التي تملكها.

Garbled Arabic: encoding, in numbersعربية مشوّهة: الترميز بالأرقام

A text file is bytes; an encoding says which bytes mean which letters. Modern files are UTF-8, but a program that sees no hint may assume an older Windows code page. The cafeteria files are plain ASCII, so they are safe — the trap springs on files you write with Arabic text. Here is a three-item Arabic menu written two ways, and what a program assuming the old English-Windows code page (Windows-1252) makes of the first one:

In the course workbook, =XLOOKUP("Latte", tblMenu[item], tblMenu[list_price]) shows #NAME?. What is the most likely explanation?في مصنّف المقرر تعرض الصيغة =XLOOKUP("Latte", tblMenu[item], tblMenu[list_price]) الخطأ #NAME?. ما التفسير الأرجح؟

#NAME? means “Excel does not recognise a name in this formula”, and an unknown function name is the classic cause. A deleted Latte row would give #N/A instead (the value is not found), a different error; the Table name tblMenu is the correct one; and Excel looks up text happily. So you diagnose by the error code, not by guessing.
الخطأ #NAME? يعني «لا يتعرّف Excel على اسم في هذه الصيغة»، واسم دالة مجهول هو السبب الكلاسيكي. أما صف لاتيه محذوف فكان سيعطي #N/A (القيمة غير موجودة)، وهو خطأ مختلف؛ واسم الجدول tblMenu هو الصحيح؛ ويبحث Excel عن النص بلا مشكلة. فالتشخيص يكون بـ رمز الخطأ لا بالتخمين.

AI lens — Excel can change a feature before your model sees itمنظور الذكاء الاصطناعي — قد يغيّر Excel ميزة قبل أن يراها نموذجك

Whatever Excel guessed on import is saved back when you press Save. Open a CSV, glance at it, save it, and an ID such as 00123 may now be 123, a text-like date may have been re-typed by the machine's regional settings, and Arabic names may be damaged. The habit that protects you is the one in Concept 4: never save over data/raw/; import with an explicit step (From Text/CSV, a File Origin, a column type) so the guess is recorded, and keep Excel for looking and for formulas you can read.

كل ما خمّنه Excel عند الاستيراد يُحفظ من جديد حين تضغط حفظ. افتح ملف CSV وألقِ عليه نظرة واحفظه، فقد يصير معرّف مثل 00123 هو 123، وقد يعيد الجهاز تنميط تاريخ شبيه بالنص بحسب إعداداته الإقليمية، وقد تتضرر الأسماء العربية. ثم يتدرّب نموذج على العمود المعدَّل ولا يظهر أي خطأ. والعادة التي تحميك هي ما في المفهوم 4: لا تحفظ أبدًا فوق data/raw/؛ واستورد بخطوة صريحة (From Text/CSV وFile Origin ونوع العمود) كي يُسجَّل التخمين، واحتفظ بـ Excel للنظر وللصيغ التي تقرؤها.

The problemالمشكلة

A machine-learning pipeline fails in the same quiet ways as this bench: a missing library falls back to a slower or different code path, a CPU build is used where a GPU build was expected, a data file has a different row count than last week. Writing that habit on a 771-line cafeteria file is cheap practice for writing it on a 7-million-row one.

def check_pins(path):
    """Compare every name==version line of a requirements file with what is installed."""
    if not path.exists():
        check(False, f"{path.name} exists", "not found")
        return
    raw = path.read_bytes()
    if raw.startswith((codecs.BOM_UTF16_LE, codecs.BOM_UTF16_BE)):
        text = raw.decode("utf-16")             # what PowerShell's > writes
    else:
        text = raw.decode("utf-8-sig")
    checked = 0
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "==" not in line:
            continue
        name, wanted = line.split("==", 1)
        try:
            have = md.version(name)
        except md.PackageNotFoundError:
            have = "not installed"
        check(have == wanted, f"pin {name}=={wanted}", f"installed: {have}")
        checked += 1
    if checked == 0:                            # a check that checks nothing must fail
        check(False, f"{path.name} has pins", "no name==version lines found")

Appendix — what activation actually doesملحق — ماذا يفعل التفعيل فعلًا

Activation is not a mode inside Python; it edits two things in the terminal session. We printed them before and after, in PowerShell:

التفعيل ليس وضعًا داخل Python؛ إنه يعدّل شيئين في جلسة الطرفية. طبعناهما قبله وبعده في PowerShell:

$env:VIRTUAL_ENV
($env:PATH -split ';')[0]

# before activation (empty) (your own first PATH folder) C:\Users\you\AppData\Local\Programs\Python\Python313\python.exe # after activation C:\Users\you\cafeteria-lab\.venv C:\Users\you\cafeteria-lab\.venv\Scripts C:\Users\you\cafeteria-lab\.venv\Scripts\python.exe

Before: no VIRTUAL_ENV, and python resolves to the system Python. After: VIRTUAL_ENV names the environment, its Scripts folder has been put first on the PATH, and so the first match for python (and for pip) is the environment's own. After deactivate the original PATH is restored — we checked: python pointed back at the system Python, and import jupyterlab failed again with ModuleNotFoundError, which is the isolation working. Because only that terminal's variables changed, another window, a notebook server started elsewhere, and a double-clicked script are unaffected. The same idea explains every “wrong Python” problem in this lesson: the PATH decides who answers.

قبله: لا يوجد VIRTUAL_ENV، ويُحَلّ python إلى Python النظام. وبعده: يسمّي VIRTUAL_ENV البيئة، ويوضع مجلد Scripts الخاص بها أولًا في PATH، فيكون أول تطابق لـ python (ولـ pip) هو الخاص بالبيئة. وبعد deactivate يُستعاد PATH الأصلي — تحققنا: عاد python يشير إلى Python النظام، وفشل import jupyterlab مجددًا بـ ModuleNotFoundError، وهذا هو العزل يعمل. ولأن متغيرات تلك الطرفية وحدها تغيّرت، فلا تتأثر نافذة أخرى ولا خادم دفاتر بدأ في مكان آخر ولا سكربت نُقر نقرًا مزدوجًا. والفكرة نفسها تفسّر كل مشكلة «Python الخاطئ» في هذا الدرس: PATH هو الذي يقرر من يجيب.
